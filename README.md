三好アキ『Next.jsでつくるフルスタックアプリ』SUpabase版を読みながら開発したものに対して、下記のデバッグと機能追加を行なったものです。

また、元々使っていたSupabaseの無料プランで作ったデータベースが途中で停止されたこともあり、データベースをNeonに置き換えました（その際ついでにSQL EditorでSQL文を書く練習も行いました）。テーブルについては[example.sql](/example.sql)を参照してください。

## デプロイ（Vercel）

https://next-market-drab-xi.vercel.app

## デバッグ

教材の指示する`src/app.item/delete/[id]/page.js`のコードには、`DeleteItem` で `image`が空文字("")のまま Image の src に渡され、Console Error が発生するバグがありました。なのでこれを直しました。

## 機能追加

- ユーザー登録を行なったときに続いてログインも行われるようにしました
- ログインを行なったときにルートページへの遷移が行われるようにしました
- ログイン中のユーザーがヘッダーに表示されるようにしました
